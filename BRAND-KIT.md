# Meraki Arts 53 Brand Kit

This brand direction uses a generated Option 4-style asset set based on the approved structure: expressive Meraki wordmark, playful brush/dot/floral details, and a matching round initials mark.

## Core Assets

- Wordmark: `/public/brand/generated/meraki-option4-wordmark.png`
- Dark-mode wordmark: `/public/brand/generated/meraki-option4-wordmark-dark.png`
- Mark / badge / loading mark: `/public/brand/generated/meraki-option4-mark.png`
- Full lockup / social preview: `/public/brand/generated/meraki-option4-lockup.png`
- Dark-mode lockup: `/public/brand/generated/meraki-option4-lockup-dark.png`
- Favicon source: `/public/brand/generated/meraki-option4-favicon.png`
- Site icon: `/app/icon.png`

## Palette

- Ink: `#28231f`
- Coral: `#d65f4d`
- Rose: `#df7b80`
- Gold: `#e1a135`
- Sage: `#7d8b68`
- Teal: `#2e7c80`
- Ivory: `#fff8eb`

## Usage

- Header: wordmark + compact mark
- Mobile/menu/favicon: compact mark
- Footer/signage: larger wordmark
- Gallery overlays: watermark asset
- Loading state: rotating loading mark
- Social share: social preview card

Keep the brand playful but not crowded. Use the dot and brush textures as accents, not as full backgrounds.
